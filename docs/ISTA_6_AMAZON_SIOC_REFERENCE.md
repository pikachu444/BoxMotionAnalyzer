# ISTA Type G/H 구현 범위

Last Reviewed: 2026-09-13

이 문서는 프로그램의 조회 범위를 설명한다. 시험 수행에는 시험소가 실제로 적용한 판본과 원문을 사용한다. 현재 공개 참조는 [ISTA 6-Amazon.com-SIOC 2018-03](https://d39w7f4ix9f5s9.cloudfront.net/32/98/c52dd6b841f18bcb8af679b1f1ac/9.TESTING_thumbnail_ISTA%20Project%206-Amazon.com-SIOC%2018-18.pdf)이며, 보유 실측 촬영의 적용 판본은 미확인이다.

규격은 운송·취급 위험에 대한 포장과 제품의 보호 성능을 평가한다. Type G/H는 TV·모니터 여부, 배송·취급 방식, 포장 중량과 girth를 함께 확인해야 한다(원문 1–3쪽). 중량만으로 H를 정하지 않는다.

| 프로그램의 항목 | 별도로 확인할 기록 | 참조 쪽 |
| --- | --- | --- |
| G01–G15 | 반복 자세를 구분하는 수행 항목과 시각 | 26, 45 |
| G16 | 선택한 취약면 또는 명시적인 미상 선택 | 45 |
| G17 | 포장 형상 분기와 hazard 사용 | 45 |
| H/B03 | 운송 자세·기울임 또는 전도 시행 | 27 |
| H/B04, H/B16의 D01–D06 | 자유낙하 항목과 적용 질량 분기 | 28, 46 |
| H/B05 | 회전 평면 낙하의 시작면·시험 모서리·해제 | 29 |
| H/B06 | 회전 모서리 낙하의 받침·지지 모서리·해제 | 30–31 |
| H/B22 | 시작면·screen 등록과 시행 단계 | 49 |

기록의 항목과 관측된 수행 결과는 별개다. B05에서는 피벗이 이미 바닥에 있으므로 박스 전체 최저점만으로 새로운 접촉을 찾을 수 없다. B06에 바닥 피벗을 강제하거나, B03/B22에 자세 복귀를 강제하지 않는다. 박스 좌표만으로 hazard 접촉·장치 지지력·해제를 확정하지 않는다. 요약표와 상세 조건의 차이를 임의로 합쳐 적합성을 판정하지 않는다.

기존 `src/simulation/scenarios.py`의 H01–12는 시뮬레이션 예제 목록이다. 이를 ISTA의 고정 12개 시험 번호나 절차 정답으로 사용하지 않는다. 접촉 형상을 아래로 향하게 하는 시뮬레이션 자세도 하나의 구성 방식이며, 실제 실험에 고유한 목표 Euler 각도가 있다는 뜻이 아니다.

촬영 해석과 좌표·단위 전제는 [실험 해석](simulation_external_reference_notes.md), 실제 Step 1 흐름과 검증 범위는 [GUI 안내](analysis/design/gui_overview.md), 저장 형식은 [결과 스키마](analysis/reference/result_schema_notes.md)를 따른다.
