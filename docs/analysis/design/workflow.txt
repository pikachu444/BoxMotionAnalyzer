현재 분석 GUI 작업 흐름

Last Reviewed: 2026-09-17

Launcher → Step 1: Scenes → Step 1.5: Process → Step 2: Results → Compare

Step 1: CSV 열기 → Detect scenes → 범위/Include/Exclude 검토 → Save and Process
- 보정은 필요할 때 검토하며 Apply는 명시적 승인이다. 변경한 보정은 별도 corrected CSV에 저장한다.
- Marker Review: 현재 치수 확인 → 전체 관측 scan → 이벤트별 국소 계산 → 승인 → Save corrected. 계산과 Done 검증은 Cancel/close로 안전하게 취소할 수 있다.
- 수동 범위 slice 저장과 검토 작업의 중간 저장/재열기도 가능하다.
- 포함 장면을 모두 저장한 뒤 정확한 파일 목록을 한 번 전달한다. 취소/부분 실패는 이동하지 않는다.

Step 1.5: Single 또는 Batch 입력 확인 → 방법 확인 → Run
- 하나의 slice는 Single, 여러 slice는 Batch로 준비한다. 자동 Run은 없다.
- 두 모드의 입력과 결과는 별도로 유지한다. 기본은 Raw, 재샘플링 OFF다.
- Single: Save and View → 저장 성공한 결과 열기.
- Batch: View Results → 이번에 저장 성공한 결과 목록 열기. 실패/건너뛴 파일은 별도 상태다.

Step 2: 현재 결과 확인 → 측정값/Plot → Point/Save point CSV 또는 Compare
- Open/Folder로 기존 결과를 바로 열 수 있다.
- Compare는 현재/선택 결과를 기존 비교 창에 추가하며 같은 경로를 중복 추가하지 않는다.
- 시간, 치수, 원본 식별과 보정/장면 이력, 미확정 항목과 비교 제외 의미를 보존한다.
